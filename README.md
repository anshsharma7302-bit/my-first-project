# 📚 Online Book Store

A simple HTML-based Online Book Store mini project created to practice web development fundamentals.

## 🚀 Features

- 🏠 Home Page
- 🔐 User Login
- 👤 User Profile / Registration
- 📚 Books Catalog
- 🛒 Shopping Cart
- 💳 Payment Section
- ✅ Order Confirmation

## 🛠️ Technologies Used

- HTML5

## 📖 Project Overview

This project demonstrates the basic structure of an online book store using HTML. It includes different sections such as user login, profile registration, book catalog, shopping cart, payment, and order confirmation.

## 🎯 Purpose

This project was created as a learning project to improve my HTML and web development fundamentals.
